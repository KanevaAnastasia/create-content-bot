# Статьи «У бабушки дома»

Канал: https://t.me/ubabushkidoma, Telegram channel ID 3993121914.
Стиль изучен по 13 публикациям 20 ноября 2026 года. Основные образцы:
https://t.me/ubabushkidoma/19, https://t.me/ubabushkidoma/18,
https://t.me/ubabushkidoma/17. Рыжий кот: Тимоша.

Первый слот: 21 ноября 2026, 09:00 Europe/Moscow. Интервал: три дня.
Слот запускает предложение тем. Публикация ждёт согласований и отдельной кнопки.
Пропущенные слоты не создают пачку заданий; незаконченная статья блокирует следующую.

Активная работа в боте имеет приоритет. Затем идёт уже ожидающая реклама,
затем статья. Обе очереди используют блокировку чата. Начатая статья удерживает
место до публикации или отмены; новые рекламные задания ждут. Неисправленная
ошибка рекламной очереди также требует завершения или отмены перед статьёй.
Команда `/articles` открывает сохранённый этап, не заменяя сессию видео.

Для явно запрошенной пробы `article_store.create_test` создаёт отдельную статью
с проверенным тестовым каналом. Она проходит те же согласования, не сдвигает
расписание и не расходует подготовленные темы основного канала. Назначение
сохраняется в самой статье и показывается на каждом этапе. После теста обычные
слоты продолжают публиковаться в основном канале. Закрытый канал адресуется
через его ID и access hash; ссылка на пост имеет вид `https://t.me/c/ID/POST`
и доступна только участникам канала.

Подборка содержит ровно четыре кулинарные темы из разных разделов и одну бытовую.
GPT рассматривает широкий круг повседневных проблем, но возвращает только пять
итоговых карточек одним вызовом. Двадцать подробных кандидатов и таблицы оценок
больше не генерируются. Приоритет у узнаваемой неприятности и ощутимого результата,
а не узких справочных сравнений. Заголовки до 40 символов, пояснение до 140.
Это редакционный выбор, а не прогноз охватов или статистика актуальных трендов.
Полные HUMAN_WRITING_RULES V3 добавляются сразу в каждый запрос на создание
и изменение текста: темы, статьи, анонсы, сценарии и описания, включая гостевые.
Повторного вызова модели для автоматического переписывания результата нет.
Программные проверки формата, длины и состава подборки остаются. Изменения
по замечаниям владельца выполняются отдельным явным шагом с теми же правилами.

Этапы: пять тем; подтверждение темы; GPT-текст и короткий анонс; согласование
текста; квадратное изображение 1:1 для Telegram и вертикальное 9:16 для сториз; согласование
картинок; отдельная кнопка публикации. Правки отправляются ответом на сообщение
бота. Старые кнопки и ответы не меняют новую версию. Согласование картинок
не публикует статью. Изменение текста снимает согласование картинок.
Анонс для сториз: одна короткая разговорная фраза или вопрос, обычно 25–45
символов, максимум 60. Например: «Что сделать с засохшим хлебом?».
Полный стиль и внешность бабушки и Тимоши задаются исходными референсами канала.
Генерируется только один вертикальный оригинал 9:16. Квадрат 1:1 вырезается
локально без второго вызова модели. Композиция должна помещать героев и предмет
в центральный квадрат; верх и низ содержат естественный фон без пустых плашек.
Кнопки «Квадрат: сдвинуть выше/ниже» меняют только обрезку, сохраняют оригинал
и требуют нового согласования картинок. Правка самого рисунка создаёт новый
вертикальный оригинал и производный квадрат.
После согласования картинок экран публикации не загружает их повторно.
Длительность генерации и показа каждого шага записывается в журнал бота.

Кнопка «Предыдущий шаг» возвращает к предыдущему согласованию, сохраняя текст
и обе картинки. Повторное движение вперёд показывает сохранённые материалы
без новой генерации. Выбор другой темы сохраняет прежние материалы в истории
и начинает новый текст. Экран выбора тем также позволяет вернуться к сохранённой
статье. Отмена статьи остаётся отдельным действием; экран отмены позволяет
вернуться к сохранённому шагу, если другая статья ещё не начата.
Во время отправки поста, проверки неоднозначного результата и после публикации
возврат назад недоступен.

После подтверждённой публикации владелец получает три отдельных сообщения:
вертикальное фото, URL поста, короткий рекламный анонс. Автопубликации в Instagram
нет. Комплект можно повторно запросить кнопкой в `/articles`.

Состояние и версии: `runtime/articles/state.json`, запись через flock + fsync +
atomic replace. Секреты там не хранятся. Образцы и изображения хранятся локально.
GPT использует существующий `openai_generate_sync`; картинки используют
настроенный `generate_image_vertex` с образцами канала, без смены провайдера.
Тексты статей и картинки генерируются после соответствующего согласования;
автоматически готовятся только темы. После сбоя требуется явный повтор этапа.
Готовый оригинал сохраняется при ошибке обрезки и используется при повторе.

Публикация использует существующую Telethon-сессию владельца и проверяет ID
аккаунта, ID канала, права и доступную длину подписи.
Если ID аккаунта ещё не сохранён, первая публикация разрешена только сессии
создателя этого точного канала; его ID сохраняется для последующих проверок.
Отправляется один пост: квадратная картинка 1:1 с полным утверждённым текстом
до 3800 UTF-16 единиц.
Telegram Premium нужен для длинной подписи. Текст не обрезается.
Перед отправкой сохраняются random_id и время; ответ Telegram проверяется
повторным чтением поста. При неизвестном результате доступна только проверка,
повторной отправки нет. Ошибки до отправки позволяют безопасный повтор.

Планировщик работает внутри процесса бота, управляемого `scripts/botctl.sh`.
Остановленный компьютер или бот не выполняет расписание; после запуска
обрабатывается один просроченный слот с сохранением календарного интервала.
