# Статьи «У бабушки дома»

Канал: https://t.me/ubabushkidoma, Telegram channel ID 3993121914.
Стиль изучен по 13 публикациям 20 ноября 2026 года. Основные образцы:
https://t.me/ubabushkidoma/19, https://t.me/ubabushkidoma/18,
https://t.me/ubabushkidoma/17. Рыжий кот: Тимоша.

Первый слот: 21 ноября 2026, 09:00 Europe/Moscow. Интервал: три дня.
Слот запускает предложение тем. Публикация ждёт согласований и отдельной кнопки.
Пропущенные слоты не создают пачку заданий; незаконченная статья блокирует следующую.

Активная работа в боте имеет приоритет. Затем идёт уже ожидающая реклама,
затем статья. Обе очереди используют блокировку чата. Начатая статья удерживает
место до публикации или отмены; новые рекламные задания ждут. Неисправленная
ошибка рекламной очереди также требует завершения или отмены перед статьёй.
Команда `/articles` открывает сохранённый этап, не заменяя сессию видео.

Этапы: пять тем; подтверждение темы; GPT-текст и короткий анонс; согласование
текста; горизонтальное изображение 16:9 и вертикальное 9:16; согласование
картинок; отдельная кнопка публикации. Правки отправляются ответом на сообщение
бота. Старые кнопки и ответы не меняют новую версию. Согласование картинок
не публикует статью. Изменение текста снимает согласование картинок.

После подтверждённой публикации владелец получает три отдельных сообщения:
вертикальное фото, URL поста, короткий рекламный анонс. Автопубликации в Instagram
нет. Комплект можно повторно запросить кнопкой в `/articles`.

Состояние и версии: `runtime/articles/state.json`, запись через flock + fsync +
atomic replace. Секреты там не хранятся. Образцы и изображения хранятся локально.
GPT использует существующий `openai_generate_sync`; картинки используют
настроенный `generate_image_vertex` с образцами канала, без смены провайдера.
Тексты статей и картинки генерируются после соответствующего согласования;
автоматически готовятся только темы. После сбоя требуется явный повтор этапа.
Готовая ориентация сохраняется при ошибке второй картинки.

Публикация использует существующую Telethon-сессию владельца и проверяет ID
аккаунта, ID канала, права и доступную длину подписи.
Если ID аккаунта ещё не сохранён, первая публикация разрешена только сессии
создателя этого точного канала; его ID сохраняется для последующих проверок.
Отправляется один пост: горизонтальная картинка с полным утверждённым текстом
до 3800 UTF-16 единиц.
Telegram Premium нужен для длинной подписи. Текст не обрезается.
Перед отправкой сохраняются random_id и время; ответ Telegram проверяется
повторным чтением поста. При неизвестном результате доступна только проверка,
повторной отправки нет. Ошибки до отправки позволяют безопасный повтор.

Планировщик работает внутри процесса бота, управляемого `scripts/botctl.sh`.
Остановленный компьютер или бот не выполняет расписание; после запуска
обрабатывается один просроченный слот с сохранением календарного интервала.
