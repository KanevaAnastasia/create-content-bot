# Рекламная очередь

В админке: **Рекламные товары** → добавить товар или **Импорт Excel**.
Поле **Тип**: **Клип** (по умолчанию) или **Пост** с одним изображением.
Обязательны название и 1–8 фотографий. Комментарий необязателен: в нём можно
указать подтверждённые свойства, предложение, ссылку для зрителя и пожелания к сценарию.
Поле «Порядок» определяет очередность; при равенстве первым идёт ранее добавленный товар.

Excel `.xlsx`: первый лист, заголовки **Название | Картинки | Комментарий**,
необязательный столбец **Тип** — Клип или Пост (пусто = Клип).
Одна строка на товар. Фото вставляются через «Вставка → Рисунки» над ячейками;
верхний левый угол каждого изображения должен быть в строке своего товара.
Формулы IMAGE, ссылки и картинки внутри ячеек не импортируются. Их можно загрузить
файлами в карточке товара. Импорт проверяет весь файл до добавления строк.
Повторный импорт создаёт новые товары; автоматического объединения по названию нет.

Расписание хранится в БД: 15 ноября 2026 в 09:00 МСК, затем 17, 19 ноября и далее
каждые два дня. В разделе **Расписание рекламы** можно поставить очередь на паузу.
Обработчик работает внутри Telegram-бота; для запуска компьютер и бот должны работать.
После простоя обрабатывается один товар без массового запуска пропущенных дней.
Дата следующего запуска сохраняется и остаётся привязана к исходному календарю.

Модель анализирует фото и комментарий, готовит продающее описание и пять сценариев
для клипа или пять текстов и промптов одной картинки для поста.
Факты не дополняются неподтверждёнными свойствами, отзывами или скидками. Русские
реплики на этапе сценария содержат больше 100 символов, без верхнего лимита.
Слишком короткие фразы разворачиваются целиком. При генерации видео действует
обычное сокращение; пользователь может править реплики перед генерацией. Фото уже подключены как
референсы для рекламных изображений. Выбор подготовленного сценария не запускает
его повторную генерацию.

Если владелец занят другой генерацией, готовый товар остаётся в очереди. Ожидание
апрува и финального рендера тоже считается активной генерацией. После завершения
обработчика бот проверяет очередь сразу, фоновая проверка — каждые 20 секунд.
Основной пользователь определяется тем же способом, что и тихий режим: активный
администратор `a_kaneva`. Ошибки не пропускают товар: исправьте карточку и используйте
действие **Повторить подготовку товаров с ошибкой**.

В финальном согласовании описаний **ОК** сохраняет результат и завершает генерацию
без публикации во всех режимах. Для отправки нужно отдельно выбрать площадки и
нажать **Публиковать выбранное**. По умолчанию площадки не выбраны. После сохранения
есть кнопка **Выбрать публикацию**; результаты также остаются на странице ролика в
админке. Когда завершён последний рекламный товар, отдельным сообщением приходит
**Пополните базу**. Отмена/начало заново не помечает товар обработанным.

После выбора сценария доступны **Клип** и **Пост**. По умолчанию выбран клип;
кнопка **ОК** подтверждает тип, заданный в карточке товара. В любом рекламном посте
только одно изображение: сначала согласование текста, затем картинки. Каждый
этап допускает перегенерацию и фидбэк. Утверждение картинки завершает пост
без автоматической публикации.
