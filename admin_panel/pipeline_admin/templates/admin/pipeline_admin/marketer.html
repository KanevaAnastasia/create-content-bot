Как читать отчёт

«—» означает нет данных, а не ноль. Просмотры разных платформ не суммируются. Сравнение — только внутри проекта, языка, аккаунта и возрастной группы, минимум с тремя другими роликами. Даже такое сравнение не доказывает причину успеха.

Это объяснимый диагностический разбор по правилам, не просмотр видео нейросетью. Советы — гипотезы для теста, не выводы о монтаже, который система не видела.
